E*TRADE OUTPUT FILES
====================

Generated Schedule FA files for E*TRADE account will be placed here.

Output files:
- schedule_fa_YYYY-YY.json        (Upload to ITR portal)
- schedule_fa_YYYY-YY.xlsx        (Review with CA - contains all sheets)
- schedule_fa_YYYY-YY_table_a2.csv (Table A2 for ITR portal)
- schedule_fa_YYYY-YY_table_a3.csv (Table A3 for ITR portal)

Excel sheets include:
- Table A2 Custodial Acc
- Table A3 Equity Interest
- Capital Gains
- Schedule OS (Dividend Income)
- Schedule FSI (Foreign Source Income)
- Excluded from A3 (Audit trail)
- A2 Peak Calculation
- A3 Peak Value Details
- Pre-YYYY Holdings Init Val
- YYYY - Daily Rates

Review the Excel file carefully before filing your ITR!
