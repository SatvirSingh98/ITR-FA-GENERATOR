================================================================================
                    INPUTS FOLDER
================================================================================

Place your E*TRADE export files here:

Required files:
  1. ByStatus_expanded.xlsx
  2. G&L_Expanded.xlsx

How to get these files from E*TRADE:
  1. Log in to E*TRADE
  2. Go to Stock Plan > My Account > Gains & Losses
  3. Export "ByStatus" report (save as ByStatus_expanded.xlsx)
  4. Export "Gain & Loss" report (save as G&L_Expanded.xlsx)
  5. Place both files in this folder
  6. Run the generator

The script will automatically find files in this folder!
================================================================================
